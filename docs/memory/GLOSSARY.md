# Доменные термины

Словарь проекта. Держать в актуальном виде — агент после обнуления контекста опирается на эти определения.

## Мультитенант

**Workspace (компания)** — тенант, одна компания-клиент. Владеет своими пользователями, каналами, контактами, диалогами. В коде — `workspaces.id`, во всех таблицах `workspace_id`.

**Superadmin** — владелец платформы, `workspace_id = NULL`. Видит все компании, создаёт новые, выдаёт права суперадминов.

**Admin (компании)** — директор компании-клиента. Внутри своей компании полный хозяин: сотрудники, каналы, настройки. Наружу не видит ничего.

**Agent (оператор)** — только отвечает клиентам. Не может создавать людей или подключать каналы.

## Сущности

**Channel (канал)** — подключение к внешней системе: VK, WhatsApp или Email. Хранит креды в `config` (JSON), имеет `webhook_secret` для неперебираемого URL.

**Contact (клиент)** — человек на другом конце. Уникален парой `(workspace_id, channel_type, external_id)`: один и тот же номер в разных компаниях — разные клиенты.

**Conversation (диалог)** — переписка с одним клиентом по одному каналу. Хранит статус, приоритет, ответственного, кэш метрик.

**Message (сообщение)** — одна реплика. Направление (`inbound`/`outbound`), автор (`contact`/`agent`/`system`), статус доставки.

**Event (событие)** — запись в таймлайне диалога: создан, статус сменён, сообщение пропущено. Не то же самое, что `Message`.

## Статусы

**Conversation.status** — `open`, `pending`, `resolved`, `closed`. При новом входящем в закрытый диалог статус возвращается в `open`, счётчик `reopen_count` растёт.

**Conversation.priority** — `low`, `normal`, `high`, `urgent`.

**Message.status** — `received` (входящее), `sent`, `delivered`, `read`, `failed`. При недоступном провайдере — `failed` с причиной в `error`, сообщение при этом сохранено.

## Метрики

**FRT (First Response Time)** — время от первого входящего клиента до первого ответа оператора. Основная метрика поддержки. Считается как разница между `first_inbound_at` и `first_response_at`.

**ART (Average Response Time)** — среднее время ответа оператора на каждое сообщение клиента. Отличие от FRT: FRT — только первый ответ, ART — все.

**Resolution Time / TTR** — от создания диалога до перевода в `resolved` или `closed`.

**SLA compliance** — доля диалогов, где FRT уложился в целевое время (`sla_seconds`, по умолчанию 900 секунд).

**Backlog** — диалоги в статусах `open` + `pending`. Считаются отдельно диалоги без ответственного.

**Reopen count** — сколько раз диалог переоткрывался после решения. Индикатор некачественного решения.

## VK

**Long Poll** — способ получать сообщения: бэкенд держит соединение с VK и ждёт событий. Не требует публичного адреса.

**Callback API** — альтернатива: VK сам присылает вебхуки. Требует публичный HTTPS, поддерживается в коде, не используется — см. ADR-009.

**Курсор `ts`** — позиция в очереди событий VK. Сохраняется в `Channel.config.long_poll_ts` после каждого опроса, поэтому перезапуск сервиса не теряет сообщения.

**`setLongPollSettings`** — метод VK, включающий приём. Вызывается автоматически при подключении канала. Параметр `enabled=1` **отдельный** от флагов событий — без него VK принимает запрос, но приём остаётся выключенным.

**`groups.getById`** — публичный метод, любой валидный токен видит любую группу. **Не годится** для проверки принадлежности токена. Использовать `groups.getLongPollSettings` — он требует прав на группу.

## Прочее

**Ingest** — процесс превращения входящего сообщения любого канала в `Contact` + `Conversation` + `Message`. Точка входа: `backend/app/services/ingest.py`.

**Webhook secret** — случайный токен в URL вебхука, `secrets.token_urlsafe(24)`. Защищает от подделки данных в чужой канал. При неверном секрете — `404`, не `403`.

**Poller supervisor** — фоновый поток, который держит по одному `VKLongPoll` на каждый включённый канал. Раз в 30 секунд сверяется с базой: новые каналы подхватывает, выключенные останавливает.

**dry_run** — параметр `POST /conversations/{id}/messages`, при котором сообщение сохраняется, но провайдеру не уходит. Для тестов на боевых каналах.
