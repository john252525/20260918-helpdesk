# Текущее состояние

Обновлено: 2026-09-21 (итерация 008)

## Работает

**Ядро.** Единый инбокс для трёх каналов, ответы из интерфейса, таймлайн событий. Сообщение сохраняется всегда, даже при недоступном провайдере.

**Мультитенант.** Компании (`workspaces`), три роли, изоляция данных проверена на двух компаниях живым тестом. Чужие данные отдают `404`.

**Каналы VK.** Две рабочие группы подключены и слушаются. Long Poll с сохранением курсора — перезапуск сервиса сообщений не теряет. Подключение через интерфейс: админ вводит ID группы и токен, жмёт «Проверить», потом «Подключить».

**Управление через UI.** Создание компании, сотрудники, подключение и удаление каналов, удаление компании, смена пароля, правка данных клиента, журнал вебхуков.

**Безопасность.** Неперебираемые URL вебхуков, журнал вебхуков за авторизацией, файлы с секретами `chmod 600`. Bootstrap-админ без явного пароля в `.env` не создаётся — нет молчаливого дефолта.

**Слой памяти и проверки.** Репозиторий git, `pre-commit` хук прогоняет четыре проверки: слой памяти, тесты валидатора, импорт бэкенда, синтаксис фронтенда. Валидатор `scripts/check_docs.py` принимает `--root` параметром. Тесты (`scripts/test_check_docs.py`) работают на копии во временной папке, боевые документы не трогают.

**Логи.** Ротация настроена, токены в логи не пишутся, ошибок нет.

## Следующее

В порядке приоритета:

1. **Callback API как альтернатива Long Poll** — переключатель на канал. Нужен при росте больше 10–15 компаний: сейчас поток на каждый канал, а VK ограничивает число подключений к одной группе.
2. **Редактирование канала** — сейчас из UI только вкл/выкл, креды не поменять.
3. **Создание диалога первым исходящим** — ручка есть в API, кнопки в UI нет.
4. **Auto-reply не должен портить FRT** — сейчас автоответ бота засчитывается как первый ответ оператора. Ждём от заказчика точный список текстов автоответов.

## Известные ограничения

- **Пароль `probnik12345`** у тестовой компании слабый, ставился для отладки. Сменить перед реальной работой.
- **WhatsApp и Email** не проверены на живом провайдере — креденшелов не было. Логика готова, вебхуки защищены.
- **VK-токен лежит в БД открытым текстом** в `Channel.config`. Это осознанное решение ради самодостаточности канала, но при ужесточении требований надо выносить в переменные окружения.
- **Только одна рабочая компания** (`whatsapi`) с реальными клиентами. Вторая (`probnik`) — тестовая, для проверки изоляции.
