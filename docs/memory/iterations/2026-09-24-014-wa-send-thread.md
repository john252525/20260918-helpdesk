# Итерация 014 — доставка ответов WhatsApp и ответы с телефона

Дата: 2026-09-24

## Цель

Две жалобы с живой проверки: ответ из интерфейса показывался «отправлено», но
не доходил; ответ, написанный с телефона, не появлялся в переписке.

## Что сделано

- `backend/app/channels/whatsapp/touchapi.py`:
  - отправка адресуется по `thread` из `Contact.meta`, числовой `msg_to` —
    фолбэк;
  - вердикт доставки читается из `results[]` (ошибка элемента или отсутствие
    id = провал), а не только из верхнего `status`;
  - нормализатор помечает `outbound` в событии и берёт peer из `thread`.
- `backend/app/services/ingest.py`: `ingest_outbound_external` — запись
  исходящего, отправленного вне приложения; идемпотентна по id сообщения.
- `backend/app/routers/webhooks.py`: `outgoing`-события больше не отбрасываются,
  а направляются в новую функцию.

## Причины (замерено на живом API)

- `msg_to` с телефоном для LID-контакта -> `"Chat not found or created"` внутри
  `results[].error` при общем `status: "ok"`. Отсюда ложное «отправлено».
- `msg={"thread": "105205425295594@lid", "text": ...}` -> `results[].status: "ok"`
  с id сообщения. Адресация по thread работает.
- Вебхуки `outgoing: true` приходят и для ответов с телефона, не только как
  эхо наших.

## Проверено

- Адресация: с `thread` уходит `msg={thread,...}`, без него — `msg_to`.
- Per-item ошибка -> `status=failed` с текстом причины.
- Сквозной вебхук-поток: входящее + ответ с телефона = 2 сообщения; повтор и
  эхо своего ответа пропущены; `thread` попал в контакт.
- Вёрстка не тронута, импорт и слой памяти зелёные.

## Заметки / дальше

- Живая проверка: ответ из UI должен дойти, ответ с телефона — появиться.
- Ограничение: писать первым в LID-диалог, где thread ещё неизвестен, нельзя;
  задокументировано в ADR-026.


## Дополнение: сторона отображения ответов с телефона

Ответ, отправленный с телефона, приходит вебхуком `outgoing: true` и по
направлению является исходящим, но владелец попросил показывать его слева —
чтобы отличать от того, что реально ушло через приложение. Такие сообщения
помечаются `meta.external` и рисуются на входящей стороне с подписью
«С телефона» и пунктирной рамкой.
